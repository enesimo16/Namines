# Namines — Frontend

Next.js 16 / React 19 / TypeScript app for the Namines interactive database architecture builder.

See the [root README](../README.md) for the full project overview and setup.

```bash
npm install
npm run dev   # http://localhost:3000
```

The frontend expects the backend at `http://localhost:5000` (override with `NEXT_PUBLIC_API_URL`).
